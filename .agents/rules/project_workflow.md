# Project Workflow Rules

1. **No Functionality Alteration Without User Approval**: Do not change or modify existing application functionality, UI flows, or features until the user explicitly approves.
2. **Database Data Protection**: Do not erase, drop, clear, or overwrite MongoDB Atlas database data without explicit user permission.
3. **Strict Step Execution**: Implement only the requested step/feature. Do not implement future steps (ML models, extra games, voice, IVR, etc.) until instructed.
4. **Preserve Project Structure & Security**: Maintain JWT auth, Node.js backend architecture, and React + Vite frontend without rebuilding the project from scratch.
